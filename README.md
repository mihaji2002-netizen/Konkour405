# فرجه ۱۴۰۵ — برنامه آماده‌سازی کنکور

وب‌اپ برنامه‌ریزی برای دانش‌آموزان کنکور ۱۴۰۵ در بازه فرجه بین نهایی شیمی و نهایی ریاضی.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## گروهها

- **گروه A**: پایه را خوانده‌اند و نیاز به مرور دهم و یازدهم دارند.
- **گروه B**: تمرکزشان روی دوازدهم بوده (برنامه به‌زودی).
