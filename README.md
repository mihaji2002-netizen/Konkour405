# برنامه جمع‌بندی کنکور ۱۴۰۵

وب‌اپ برنامه‌ریزی برای دانش‌آموزان کنکور ۱۴۰۵.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## گروهها

- **گروه A**: پایه را خوانده‌اند و نیاز به مرور دهم و یازدهم دارند.
- **گروه B**: تمرکزشان روی دوازدهم بوده (برنامه به‌زودی).
